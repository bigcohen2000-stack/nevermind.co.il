## Blueprint Improvement

Improve the original blueprint while keeping the core idea.

Focus on:
- clearer structure
- better user experience
- simpler technical stages
- better content architecture
- better mobile-first layout
- clean minimal design

## Design Direction

The design must follow the blueprint:

- minimalist
- no drama
- clean typography
- fast loading
- no unnecessary effects
- no heavy animations
- no gradients
- no excessive shadows

Main colors:

- Background: #FAFAF8
- Main text: #1A1A1A
- Action red: #D42B2B
- Muted gray: #9CA3AF

## Language Direction

The site will likely use Hebrew content.

If Hebrew is used:
- use RTL correctly
- align text to the right
- avoid broken mixed-direction layout

## Claude Behavior

But stop and ask before:
- choosing payment system
- choosing auth system
- changing the business model
- deleting content
- adding external services
- changing the core philosophy of the blueprint
